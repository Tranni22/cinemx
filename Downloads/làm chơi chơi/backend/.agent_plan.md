# Kế hoạch Tái Cấu Trúc Logic Báo Cáo: 3 Nút Chốt Độc Lập & Chuẩn Khung Thời Gian Tuần/Tháng

- [x] **1. Mở rộng Database Schema (db.js)**
  - Tạo/Nâng cấp các bảng lưu trữ lịch sử chốt báo cáo độc lập:
    + `shift_reports` (lưu chốt ca)
    + `daily_reports` (lưu chốt ngày)
    + `weekly_reports` (lưu chốt tuần: khung Thứ 2 -> Chủ Nhật chuẩn 7 ngày)
    + `monthly_reports` (lưu chốt tháng: khung Ngày 01 -> Ngày cuối tháng 28/29/30/31 chuẩn)

- [x] **2. Tái cấu trúc Backend API (`server.js`)**
  - **Khung thời gian Tuần chuẩn**: Tính từ Thứ 2 00:00 đến Chủ Nhật 23:59:59 của tuần hiện tại (VD: `10/08/2026 - 16/08/2026`).
  - **Khung thời gian Tháng chuẩn**: Tính từ Ngày 01 00:00 đến Ngày 28/29/30/31 23:59:59 của tháng hiện tại (VD: `01/08/2026 - 31/08/2026`).
  - **Xây dựng 3 Endpoint Chốt Riêng Biệt**:
    1. `POST /api/reports/close-shift` (Chốt Ca / Chốt Bây Giờ): Lưu `shift_reports`, cập nhật `daily_reports`, reset bàn, reset doanh thu ca.
    2. `POST /api/reports/close-week` (Chốt Báo Cáo Tuần): Tính toán tổng doanh thu tuần hiện tại (chuẩn 7 ngày), lưu vào `weekly_reports`, reset chỉ số tuần mới.
    3. `POST /api/reports/close-month` (Chốt Báo Cáo Tháng): Tính toán tổng doanh thu tháng hiện tại (chuẩn 28-31 ngày), lưu vào `monthly_reports`, reset chỉ số tháng mới.

- [x] **3. Cập nhật Giao diện Admin Dashboard (`AdminDashboard.jsx`)**
  - Đặt **3 Nút Chốt Riêng Biệt** có màu sắc và icon trực quan:
    + `⚡ Chốt Ca / Bây Giờ` (Đỏ)
    + `🗓️ Chốt Báo Cáo Tuần` (Tím/Xanh)
    + `📆 Chốt Báo Cáo Tháng` (Xanh lá)
  - Hiển thị Khung thời gian chuẩn của Tuần hiện tại và Tháng hiện tại rõ ràng trên thẻ KPI.
  - Hiển thị chuẩn 4 Tab Lịch Sử: **Theo Ca**, **Theo Ngày**, **Theo Tuần (7 ngày chuẩn)**, **Theo Tháng (28-31 ngày chuẩn)**.

- [x] **4. Kiểm tra Cú pháp, Test Trình Duyệt & Commit Push Git**
  - Kiểm tra cú pháp, test thử luồng chốt 3 nút riêng biệt và kiểm tra tính nhất quán dữ liệu.
  - Push code mới lên GitHub repository.
